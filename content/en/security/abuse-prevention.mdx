<Step id="abuse" title="Attacks that use the product as designed">

Abuse is your own login, sign-up, search and checkout used **at scale with bad intent**. Every request is valid; the signal is the **pattern**.

<Step id="stuffing" title="Credential stuffing beats per-IP limits">

**Credential stuffing** replays leaked username and password pairs, betting on reuse. Residential proxy pools make each IP look like one household, so per-IP limits barely help.

]} edges={[{ from: "bot", to: "px" }, { from: "px", to: "login", label: "valid-looking" }]} caption="A global failure spike is the tell." />

<Step id="signals" title="Layer the signals">

No single signal holds. Stack signals that are costly to fake together.

  prompt="Which measures meaningfully reduce credential stuffing? Select all that apply."
  options={[

    { id: "mfa", text: "Offer and encourage multi-factor authentication, and require it for risky sign-ins", correct: true, feedback: "Right. A correct leaked password is no longer enough to take over the account." },

<Step id="false-positives" title="The base-rate trap">

Most traffic is legitimate, so even a 1% false-positive rate can block more good users than bad. Compute the **share of blocks that are false**.

<Step id="friction" title="Graduated friction">

Respond in proportion to risk. Never reveal which signal fired.
