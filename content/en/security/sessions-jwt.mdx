<Step id="two-designs" title="A pointer or a passport">

A JWT is **signed, not encrypted**: never put secrets in it.

<Step id="validate" title="Validating a JWT">

Most JWT bugs trust the token's own header: `alg: none`, or **algorithm confusion** (RS256 server tricked into HS256 with its public key). Pin the algorithm and key on the server (RFC 8725).

]} edges={[{ from: "t", to: "v" }, { from: "v", to: "api", label: "if all pass" }]} caption="Decoding is not verifying." />

<Step id="revocation" title="Revoking a token that verifies itself">

A self-contained token cannot be deleted. Wait out `exp`, or keep a **denylist** of revoked `jti`. Entries only live until the token would expire, so size = revocations per time × token lifetime (Little's law). Checking it per request is the lookup JWTs avoided, but a far smaller set.

<Step id="lifetime" title="Short access tokens, rotating refresh tokens">

**Short access tokens** (minutes, verified locally) plus a **refresh token** only the auth server accepts. **Rotation**: each refresh returns a new token; reuse of an old one reveals theft and revokes the family (RFC 9700). Shorter lifetimes cost refresh traffic.

<Step id="storage" title="Where the browser keeps it">

Anything JavaScript can read, XSS can steal. Regenerate the session ID at sign-in.

<Compare title="Cookie attributes" sides={[

]} />
