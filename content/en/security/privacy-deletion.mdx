<Step id="minimise" title="The safest data is data you never kept">

A breach can only leak what exists. GDPR Art. 5 and 25: **minimisation**, **storage limitation**, protection **by design and by default**.

<Compare title="Step totals feature" sides={[
  { title: "Keep every GPS point forever", tone: "bad", points: ["Years of home and work", "Must secure, disclose, delete"] },
  { title: "Keep weekly totals", tone: "ok", points: ["Feature still works", "Delete raw points after processing"] }
]} />

<Choice
  id="minimise-choice"
  objective="minimise-data"
  prompt="A fitness app wants to show users their weekly step totals. The prototype stores every raw GPS point forever. What do you change?"
  options={[
    { id: "aggregate", text: "Keep the weekly totals the feature needs, and delete raw location points after a short processing window", correct: true, feedback: "Right. The feature works, and a breach no longer reveals years of where each user lives and goes." },
    { id: "encrypt", text: "Keep everything, but encrypt it", feedback: "Encryption is worth having, but the app still holds a lifetime of location history it does not need, and has to protect, disclose and delete it." },
    { id: "anonymise", text: "Remove the user's name from the GPS traces", feedback: "Location traces are highly identifying on their own: home and work locations re-identify most people. Removing the name is not anonymisation." },
    { id: "keep", text: "Keep it all in case a future feature needs it", feedback: "'In case' is not a purpose. Storage limitation exists to stop exactly this, and the risk grows every day you keep it." }
  ]}
/>

</Step>

<Step id="copies" title="Find every copy">

<Step id="pipeline" title="A deletion pipeline">

Deletion is a workflow with an owner, an audit trail and a deadline: one month, extendable by two (GDPR Art. 12(3)).

<Timeline title="Deletion pipeline" events={[
  { at: "1", label: "Verify requester", tone: "info" },

  { at: "4", label: "Event to copies, acks", tone: "warn" },
  { at: "5", label: "Audit log, confirm", tone: "ok" }
]} />

<Ordering
  id="deletion-pipeline"
  objective="map-data-copies"
  prompt="Order a robust account-deletion pipeline."
  items={[
    { id: "verify", text: "Verify the request comes from the account holder" },

<Step id="backups" title="Backups and the last copy">

Backups are immutable by design. Keep retention short and documented, re-apply deletions on restore, and treat erasure as done when the last copy expires.

<Step id="crypto-shred" title="Crypto-shredding">

**Crypto-shredding**: encrypt each user's data under a per-user key, and destroy the key to erase every copy, including immutable backups (NIST SP 800-88). Plaintext, derived data, processors and key backups escape it.

<Flow title="Destroy the key" height={150} failed={["k"]} nodes={[
  { id: "k", label: "User key", kind: "kvStore", x: 0, y: 50, note: "destroyed" },
  { id: "d", label: "Ciphertext copies", kind: "database", x: 100, y: 50, note: "DB, replicas, backups" }
]} edges={[{ from: "k", to: "d" }]} caption="Ciphertext stays, unreadable." />
