  prompt="You shard a 500M-player leaderboard across 16 Redis shards by `hash(userId) % 16`. How must the API compute a player's exact global rank?"
  options={[
    { id: "scatter-zcount", text: "Look up the player's score on their home shard, then query all 16 shards for the count of players above that score and sum the results", correct: true, feedback: "Right. Because higher-scoring players are hashed uniformly across all 16 shards, no single shard knows the global rank without summing counts across shards." },
    { id: "local-zrevrank", text: "Call ZREVRANK on the player's home shard and multiply by 16", feedback: "Multiplying by 16 is only an estimate; for top players (#1 vs #15) a statistical estimate is wrong." },
    { id: "impossible", text: "Exact rank is impossible with hash partitioning", feedback: "It works via scatter-gather `ZCOUNT` across the 16 shards, trading read fan-out for simple single-shard writes." }
