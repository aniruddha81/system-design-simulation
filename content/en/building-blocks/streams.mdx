<Step id="time" title="An event has more than one clock">

**Event time**: when it happened. **Processing time**: when the pipeline sees it. Validate timestamps at ingestion; a far-future clock distorts progress.

<Step id="windows" title="A window boundary needs a convention">

Tumbling window, **[start, end)**: **start = floor(timestamp / width) × width**. State the alignment; local days are not always 24 hours.

<Step id="watermark" title="A watermark estimates progress">

A watermark **estimates** event-time progress. It is not a barrier: older events can still arrive. The slowest input (or an idle partition) holds it back. Advance fast for latency, wait for completeness.

]} />

<Step id="late-data" title="Late events need a visible result policy">

Window ends at 120 s, allowed lateness 30 s: keep state until the watermark reaches **150 s**. Early results are provisional; updates replace, never add. Count and report dropped late data.

<Step id="dedup" title="Deduplication spends bounded state">

<Step id="sink" title="Replay safety must reach the sink">

Replay can repeat external effects. Make the sink idempotent: upsert by metric, entity and window with a version check, or send uniquely identified deltas.
