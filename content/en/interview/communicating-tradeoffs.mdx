<Choice
  id="db-choice"
  objective="tie-to-requirements"
  prompt="Your requirements include 'no double-booking of a seat' and 'about 500 bookings per second at peak'. How do you justify the database choice?"
  options={[
    { id: "req", text: "'A relational database with a unique constraint on (event, seat) makes double-booking impossible at the storage layer, and 500 writes per second fits one well-provisioned primary.'", correct: true, feedback: "Right. Each clause answers a stated requirement with a mechanism and a number." },
    { id: "popular", text: "'PostgreSQL is popular and well supported.'", feedback: "Popularity is not one of the requirements. Say which requirement the choice satisfies and how." },
    { id: "nosql", text: "'NoSQL, because it scales to millions of writes per second.'", feedback: "500 writes per second does not need that, and you have not addressed double-booking, the hardest requirement." },
    { id: "both", text: "'Both SQL and NoSQL, to get the best of both.'", feedback: "Two databases double the operational cost and add a consistency problem between them. It needs a reason, not a hedge." }
  ]}
/>

</Step>

<Choice
  id="pushback-response"
  objective="tie-to-requirements"
  prompt="You chose fan-out on write for timelines. The interviewer asks: 'What happens when a user with 50 million followers posts?' What is the best response?"
  options={[
    { id: "adapt", text: "'That is 50 million inserts per post, so delivery would lag for minutes. I'd treat high-follower accounts separately: skip fan-out for them and merge their posts at read time.'", correct: true, feedback: "Right. You quantified the concern, accepted what it breaks, and adapted the design with a reason." },
    { id: "defend", text: "'It will be fine; the queue will absorb it.'", feedback: "A queue absorbs bursts but does not make 50 million inserts fast. Dismissing a valid concern without numbers is a red flag." },
    { id: "abandon", text: "'You're right, I'll switch everything to fan-out on read.'", feedback: "Folding completely throws away the benefits for the other 99.9% of users. Change only what the concern actually breaks." },
    { id: "deflect", text: "'That's an edge case; let's ignore it.'", feedback: "Celebrities generate a large share of reads and writes. Edge cases at scale are the interview's deep dives." }
  ]}
/>

</Step>
