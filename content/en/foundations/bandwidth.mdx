<Step id="units" title="A byte is eight bits">

Links are sold in **bits**, responses are measured in **bytes**. Divide by 8. Here 1 MB = 1,000,000 bytes (a MiB is 1,048,576).

<Stats title="Ideal payload rate" items={[
  { label: "Link", value: "100 Mbit/s" },
  { label: "÷ 8 bits per byte", value: "12.5 MB/s", tone: "ok", sub: "before overhead" }
]} />

]} />

</Step>

<Step id="transfer" title="Separate serialization from propagation">

Serialization = bytes × 8 ÷ link rate. Propagation, queueing and server work add on top.

<Flow title="50 MB over 100 Mbit/s" height={140} nodes={[
  { id: "s", label: "Sender", kind: "service", x: 0, y: 50 },

]} edges={[{ from: "s", to: "c", label: "50 × 8 / 100 = 4 s" }]} caption="A faster link cuts serialization. A closer cached copy cuts propagation." />

<Step id="load" title="Aggregate traffic saturates a shared link">

Demand = rate × size. Workers only enqueue bytes faster; they cannot widen the link.

<Bars title="Demand versus link (Mbit/s)" items={[

<Step id="queue" title="Bandwidth contention becomes latency">

Ten 10 MB responses on a 10 MB/s FIFO link: the last waits 10 s with CPU idle. Bound queued bytes, not just request counts.

<Step id="compression" title="Compression trades CPU for fewer bytes">

Compression trades CPU for bytes. Text and JSON shrink well; images and video often do not. Cache public, versioned assets at the edge. Private responses need explicit cache policy.

<Compare title="Cut origin egress" sides={[
  { title: "Compress", tone: "info", points: ["Fewer bytes sent", "Costs CPU", "Skip compressed media"] },
  { title: "Edge cache", tone: "ok", points: ["Fewer origin fetches", "Version the URL", "Key by representation"] },
  { title: "Never", tone: "bad", points: ["Path-only key on private data", "Leaks one user's data"] }
]} />

<Choice id="cdn-choice" objective="relieve-link-saturation" prompt="Public versioned JavaScript bundles dominate origin egress. Which change is a strong fit?" options={[
  { id: "cdn", text: "Compress once and cache immutable versioned assets at the edge", correct: true, feedback: "Right. Reuse reduces origin fetches, while compression reduces bytes delivered. Verify cache keys and content encoding." },
  { id: "private", text: "Cache every authenticated response under its path alone", feedback: "Different users can receive different data at the same path. A shared path-only cache can leak private responses." },
  { id: "recompress", text: "Recompress every already compressed image at maximum effort", feedback: "That can consume CPU for little size reduction. Measure format-specific benefit first." }
]} />

</Step>

<Step id="egress" title="A cache hit changes who sends the bytes">

Cost = billable GB × price per GB. Edge delivery is still billed, so a 90% origin hit rate does not cut 90% of the bill.
